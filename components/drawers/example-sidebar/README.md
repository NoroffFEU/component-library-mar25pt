# Drawer

A slide-out sidebar panel with overlay backdrop.

## How to use

Copy the `.drawer-overlay` HTML. Click the trigger button to open, click the X or the overlay to close.

## Design decisions

- Slides in from the left with a smooth transition
- Overlay backdrop semi-transparent to focus on the drawer
- Clicking the overlay closes the drawer
- Menu scrolls independently if content overflows

## Known limitations

- Only slides from left — no right/top/bottom variants
- No focus trap for keyboard navigation
