# Neon Button

A glowing neon-style button with a hover effect.

## How to use

Copy the HTML for the `<button class="neon-button">` element and include the CSS from `style.css` in your project.

## Design decisions

- Dark background to make the glow effect visible
- Cyan colour chosen for a classic neon look
- A sweep animation on hover adds a subtle light reflection
- `text-transform: uppercase` and `letter-spacing` give it a tech/futuristic feel

## Known limitations

- The glow effect only looks good on dark backgrounds
- No focus styles yet — would need adding for accessibility
